# EPOCH - Diabetes: Data Dictionary

File: `train.csv` (4,120 rows)

| Column | Description |
|---|---|
| `patient_id` | Unique patient identifier |
| `age` | Age at admission (years) |
| `gender` | Patient gender |
| `admission_date` | Date of hospital admission |
| `bmi` | Body mass index |
| `waist_cm` | Waist circumference |
| `fasting_glucose` | Fasting blood glucose |
| `hba1c` | Glycated haemoglobin (3-month average blood sugar) |
| `bp_systolic` | Systolic blood pressure |
| `cholesterol_total` | Total cholesterol |
| `hdl` | HDL cholesterol |
| `triglycerides` | Triglycerides |
| `years_since_diagnosis` | Years since diabetes was diagnosed |
| `medication` | Current diabetes medication |
| `physical_activity` | Self-reported activity level |
| `smoking_status` | Smoking history |
| `visits_last_year` | Clinic visits in the past year |
| `length_of_stay_days` | Length of this hospital stay |
| `readmitted_30d` | Readmitted within 30 days of discharge |
| `readmission_ward` | Ward |

Not everything is documented. If something is unclear, ask a mentor - just as you would ask a data owner on a real project.
